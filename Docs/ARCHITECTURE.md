# 架构与尺度

## 模型坐标与渲染边界

`UniversalPosition` 由三个 int64 扇区索引和一个 double 三维局部偏移组成。扇区边长 `10^12 m`，局部坐标归一化到 `[-5×10^11, 5×10^11)`。相邻坐标先相减整数扇区，再合成相对米制距离；不把银河绝对位置放进一个 double，也不直接写入 Transform。

观察者相机始终在 Unity 原点。天体中心、网格块锚点先在 double 中减掉观察者，再转 float；网格顶点也先减去各自的 double 块锚点。全局渲染比例随海拔变化，独立于模型 SI 尺度。地表附近比例为 1。极远天体使用共同单调深度映射的角尺寸代理，保存角位置和半径比；这属于可视化投影，不改变模型轨道或尺寸。最远点源星星投影到远裁面以内的壳面，其方向每帧从真实程序化位置重新计算。

整数范围很大并不意味着所有距离运算都具有毫米精度。远距离相减的结果仍是 double；保证的是同一局部邻域在任意可表示扇区上的细小位移。远端 GPU 深度压缩、有限采样的大气和极端相切轮廓还有精度边界。

## 确定性模型

宇宙 Seed 和四光年单元地址哈希到候选恒星系 Seed。六分量银河模型在抖动后的候选位置提供 stars/pc³ 密度，独立哈希流按 `1-exp(-density*cellVolume)` 决定准入；每格最多解析一个恒星系。高密度区其余恒星由远端人口聚合表示。原点是显式保留的起始恒星系。候选生成、准入、流送和存档恢复共享同一个银河配置；具体公式见 `Core/GALAXY.md` 和 `Core/POPULATION.md`。

银河中心相对原点位于 -26,700 ly，默认盘直径 104,000 ly，恒星晕半径 160,000 ly。薄盘、厚盘、对数旋臂、核球、棒和恒星晕都占据三维空间，边缘平滑衰减。远端 60,000 个 Seed 人口光核存储 galactic ly 坐标，在 GPU 上依据同一观察者重投影；没有固定天空盒。光核是人口外观采样，和局部单星目录不逐颗一一对应，近处平滑淡出以减小重复显示。float ly 的量化只用于远端聚合渲染；飞行、天体和地形仍保持扇区加局部 double。

每颗行星拥有米制半径、质量、轨道根数、地形幅度、海洋、大气和颜色参数。开普勒方程使用带保护的求根与解析双体轨道，所有角度使用弧度。它不是 N 体重力积分。近行星飞行在该天体移动参考系内跟随轨道平移；自由飞行进入另一行星邻域时自动切换参考体且保留观察者位置。

生成版本 2 区分红矮星、主序星、蓝主序星、红巨星、白矮星、中子星和恒星黑洞。每个恒星系有五颗主行星与 1–3 颗卫星，覆盖海洋、岩石/沙漠、冰、气态巨行星、冰巨星以及熔岩卫星。卫星轨道以母星质量和相对位置求值，再递归合成系统位置。月球轨道受保守 Hill 范围限制；这些是便于开发探索的多样性预设，并非恒星/行星发生率或恒星演化模拟。

地形只依赖方向、行星参数和 Seed。连续三维梯度噪声生成大陆和山脊，额外物理频段覆盖 10 km、1.6 km、200 m、25 m 和 6 m，最终使用平滑界限保持高度范围。海洋行星把渲染及碰撞查询的负高度钳制到海平面。当前没有水下地形、洞穴、侵蚀或动态海浪。

岩石/冰世界加入真实几何陨坑，沙漠使用高程层理，熔岩裂隙具有几何凹陷和逐像素 Seed 发光场。逐像素场由有界块锚点构建，防止近地坐标相减损失，也避免以顶点插值显示裂隙造成三角网格花纹。GPU 发光是 CPU 地质的外观近似，不声称逐位相等。

## 自适应行星

每颗行星使用六个立方球面图的四叉树。观察距离和块覆盖尺度决定细分；地平线剔除、叶块预算和驻留预算限制工作。父块在可见子块准备齐全之前保留，防止生成中的洞。每帧块数和毫秒预算控制构建，CPU 同步生成一个块是最小任务单位，因此单块可能超过毫秒预算。0.4 的子顶点保存对应父三角形上的位置、法线、颜色与未钳制高度，沿平滑曲线变成真实细节，合并可反向进行。Forward、DepthOnly、DepthNormalsOnly 共用相同变形；保守 Bounds 包括两个端点。细分和合并使用可配迟滞，过渡中的完整兄弟组受驻留保护；删除原先随高度切换的最低 LOD 阶跃。裙边仍覆盖相邻 LOD 接缝，尚无完整的相邻等级平衡。

连续高度采样用于网格、法线和地表高度约束。该约束不是 PhysX 全行星 MeshCollider，也不是角色重力/刚体模拟。观察者是六自由度探索相机，可降落、低空移动和起飞。

## 渲染

- URP 地表 Shader 的可见材料改为逐像素求值。可见固体行星延迟生成六面 RFloat 高度数组（默认每面 1024²，含 mip 约 32 MiB），GPU 使用与 CPU 相同的 Seed 哈希、梯度噪声与陨坑参数。负格点的 64 位进位用有界 16 位相加，避免符号扩展后丢失进位。几何与碰撞仍来自原 CPU 高度场，生成版本不变。海岸取高度零轮廓，区域气候读取平滑 mip；米制细节在局部块锚点下计算并做像素导数过滤。海洋单独使用可配置粗糙度及 GGX 反射。顶点颜色只作材料图尚未就绪时的回退及诊断。
- 恒星拥有程序化表面和温度颜色；远恒星使用三维目录点源代理，亮度经过曝光压缩和最低可见角尺寸，尚非绝对星等测光。
- 银河的主要画面改为 `GalaxyVolume`：GPU 在实际观察者方向上积分有限薄/厚盘、旋臂、棒/核球与晕的发光及 RGB 尘埃透射，0.4 默认原生分辨率 HDR 目标、外部 128 步及内部 224 步；近处 8,000 光年优先分配样本，三维尘埃细丝与成星团块按像素和步长过滤。全屏几何在最远深度合成，不能覆盖不透明天体；D3D 的 Blit 与场景网格 Y 方向显式转换。内外曝光与亮度压缩为显示控制，未校准绝对测光。人口光核保留为较暗、较小的细节点源。观察者、精确姿态、FOV、质量/光学参数或结构变化均重算，静止复用缓存；提交 CPU 时间不等于 GPU 执行时间。
- 气态巨行星的云带、涡旋、差异风和公里级细节由 Seed 与模拟时间生成；环使用解析透明度与相互遮影，细环以屏幕导数过滤。气态天体没有可降落的固体地面；CPU 云顶安全边界保持物理半径。
- 气态参考球的网格只是保守膨胀的光栅覆盖。颜色与 DepthOnly 在同一个解析 ray–sphere 命中上重建法线、程序化方向和 `SV_Depth`；越过相机 far plane 的包围壳可裁剪投影，但实际命中仍检查 near/far。近景地平线由物理球面决定，避免数千米弦面误差；它没有添加可降落的气态地面。
- 海洋星球增加独立薄云外壳，默认高 12 km，以 Seed、天气覆盖与模拟风生成光学厚度及边缘细节。薄云在相机进入前淡出，避免成为穿越时的平面天花板；不改变地形高度、参考体或碰撞。没有地表云影、体积穿云或气象求解。
- 表面直接照明由恒星真实光度与轨道距离推导后作显示压缩；黑洞自身不发光。中央黑洞依据可配置质量显示 Schwarzschild 半径的几何参考面，尚无引力透镜、吸积盘或相对论轨迹。固体地形暂不随自转旋转，云带与气态星体外观按自转周期更新。
- 大气使用可配置 Rayleigh/Mie 密度和采样路径积分；分别合成 RGB 透射和单次入射散射，并使用相机深度终止地表路径。未实现多次散射、臭氧、体积天气或科学级太阳光谱。
- `Resources/UniverseSettings` 持久化 Seed、地形预算、采样数、光学系数、曝光、视场和材质。游戏内设置可调曝光、视场、星星亮度、地形预算与 Seed；其他参数通过 Inspector 调整。

## 运行与验证

`UniverseApp` 维护观察者、时钟、当前系统和参考体。星际自由飞行从观察者扇区估计空间地址，每 0.25 秒刷新局部目录并选择最近的已准入恒星系；切换恒星系保留观察者坐标。超高速飞行会跳过短暂穿越的局部目录，银河空间投影每帧连续更新；并未验证逐颗遍历整个银河。行星定位、恒星定位、银河概览和 N 键跳转是明确的便捷传送，连续下降/上升和 WASD 飞行走同一高精度状态链。探索速度可以超过光速，当前不模拟相对论。

存档写临时文件再原子替换并保留备份，载入前验证位置、时间、姿态、生成版本和银河参数。生成版本 2 使用 `flight-v2.json`，保留旧 `flight.json` 供 0.1.0 程序打开，不将新地形错误套用到旧坐标。测试保护用户已有存档。结构参数在启动/载入配置时生成，运行中直接原位修改银河结构对象暂不支持重建；曝光、尘埃和光核尺寸每帧可调。

EditMode 验证数学与网格；PlayMode 验证原生对象生命周期、碰撞高度、参考体/星系切换与存档；GPU 像素验证分离天空、真空、缩放及近地深度；完整航线另外保存真实屏幕截图和帧耗时。自动断言通过仍须检查截图，本项目保留首轮视觉失败及修复证据。

近地材料的物理像素足迹使用相机相对 `positionWS / renderScale` 的导数。不能用 `ddx(unitPlanetDirection) × radius` 恢复厘米级位移：约六百万米半径下，float 单位方向的量化已大于近地像素。微法线使用有界米制噪声的解析梯度，投影到真实网格法线的切平面。独立地面 fixture 使用真实行星半径、CPU 网格、2 m 净空、2 mm 位移和两种渲染比例，补上小型平面测试未覆盖的精度路径。

材料图默认每张约 32 MiB，已访问的同系统固体天体保留各自地图直到系统销毁。`totalMaterialMapBytes` 是所有这些高度图的估算合计，不包括其他 GPU 资源；`Profiler.GetTotalAllocatedMemoryLong` 也不是总显存或 OS RSS。首次六面烘焙不受 CPU 网格毫秒预算限制，完整降落的实际帧间隔及天体巡检冷接近统计单独保留，不能用静止缓存或 CPU 提交时间声称没有冷启动开销。

## 0.4 探索工具与中文

`CelestialTarget` 是系统地址加天体索引，位置随模拟时间由同一层级开普勒模型求值。`ExplorerTools` 管理目标、目录、导航、轨道、书签及截图；`ExplorerHud` 管理主界面与设置。捆绑 Noto Sans CJK SC 字体和 OFL 授权，实际天体名称与 SI 单位保留。

选择和居中不改变观察者位置；跟踪持续更新朝向。连续飞往先在原坐标中接近，进入目标50倍半径时保留观察者，交接当地参考体与径向下降。F/V 等明确的快捷跳转单独命名。搜索按已生成的真实类型、海洋、大气、卫星、可降落与物理距离筛选，来源是当前和局部流送目录；地址生成支持额外指定单元，不声称全宇宙穷尽搜索。输入框打开期间阻止飞行快捷键与速度滚轮。

`OrbitPath` 在真实 SI 轨道上取样，`OrbitOverlay` 递归合成运动母体的位置，使用与天体相同的深度映射及像素宽度丝带。轨道默认关闭，V总览或O开启。标签避让和暗色背板保证云层上可读，银河尺度隐藏本地标签。选中目标与遥测参考体分别显示。

书签与飞行存档共享状态校验、扇区位置与精确十进制局部坐标。新增可选 `ExactLocal` 字段规避 JsonUtility double 写出舍入，仍读旧版生成2文件；原子替换保留备份。自动测试通过临时书签路径保护用户数据。F7 截图写入应用 persistentDataPath/Screenshots。

## 0.5 天体数据与版本恢复

`PlanetScience.Evaluate` 是使用 SI 单位的纯计算入口；`CelestialDetailsPage` 只负责四页中文展示与目标选择。详情直接读取目标的系统、种子和层级轨道，不借用相机当前参考行星的数据。质量和半径推导密度、重力及逃逸速度；轨道周期使用直接母体质量，卫星受光距离则递归累加到恒星。恒星有效温度用同一光度和半径求解。

大气成分、压强、反照率、内部热和灰吸收系数由独立种子流决定，不能改变原生成器随机序列。零维辐射平衡区分平衡温度、含内部/潮汐热的有效温度与单层灰大气参考温度；气体参考层使用理想气体密度和标高。同步小偏心率卫星可加近似潮汐热，其耗散参数作为假设显示。每项注明生成、推导、假设、估计或未建模；气巨使用 1 bar 参考层，固体地表温度为空。详细公式及相变、天气、卫星食等限制见 [0.5 验收说明](VALIDATION-V050.md)。

默认生成版本 3 在版本 2 原始序列之后执行 `PlanetGenerationRules`：按参考海洋世界的简化热模型反求一级轨道布局，保留质量、半径、种子和地形参数，检查表面/Roche 净空与相邻间隔。无吸积黑洞的零恒星辐照会将原海洋外观改为冰封，并不设置固体天体大气包络。这不是行星形成或长期 N 体稳定性模拟。版本 2 的恢复跳过此规则，保留原世界并提示旧外观/气候可能不一致。

`WorldGenerationVersion` 随飞行状态恢复，默认新存档为 `flight-v3.json`。若其缺失可读取 `flight-v2.json` 并切换为原生成版本，后续仍保存到该版本路径且保留原子备份；新版本不会静默覆写旧世界。运行测试使用单独临时保存目录，避免修改用户飞行状态。

模拟与输入保留在 `Update`；相机、遥测和世界渲染提交移动到 `LateUpdate`，在普通协程完成导航/恢复后提交新系统，再由目标跟踪/环绕修正姿态。该时序解决协程替换世界后到帧末尚未提交新地形的一帧空场；首次预算覆盖和实际独立程序帧缓冲另有验证。
