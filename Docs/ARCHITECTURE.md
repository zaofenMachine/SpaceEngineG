# 架构与尺度

## 模型坐标与渲染边界

`UniversalPosition` 由三个 int64 扇区索引和一个 double 三维局部偏移组成。扇区边长 `10^12 m`，局部坐标归一化到 `[-5×10^11, 5×10^11)`。相邻坐标先相减整数扇区，再合成相对米制距离；不把银河绝对位置放进一个 double，也不直接写入 Transform。

观察者相机始终在 Unity 原点。天体中心、网格块锚点先在 double 中减掉观察者，再转 float；网格顶点也先减去各自的 double 块锚点。全局渲染比例随海拔变化，独立于模型 SI 尺度。地表附近比例为 1。极远天体使用共同单调深度映射的角尺寸代理，保存角位置和半径比；这属于可视化投影，不改变模型轨道或尺寸。最远点源星星投影到远裁面以内的壳面，其方向每帧从真实程序化位置重新计算。

整数范围很大并不意味着所有距离运算都具有毫米精度。远距离相减的结果仍是 double；保证的是同一局部邻域在任意可表示扇区上的细小位移。远端 GPU 深度压缩、有限采样的大气和极端相切轮廓还有精度边界。

## 确定性模型

宇宙 Seed 和空间单元整数地址哈希到恒星系 Seed。四光年单元内加入确定性的抖动，每个单元生成一颗恒星及 4–7 颗行星。原点单元位于原点。当前是稀疏、可扩展的恒星种群模型，尚未构建银河密度场、真实星表、双星或宇宙学结构。

每颗行星拥有米制半径、质量、轨道根数、地形幅度、海洋、大气和颜色参数。开普勒方程使用带保护的求根与解析双体轨道，所有角度使用弧度。它不是 N 体重力积分。近行星飞行在该天体移动参考系内跟随轨道平移；自由飞行进入另一行星邻域时自动切换参考体且保留观察者位置。

地形只依赖方向、行星参数和 Seed。连续三维梯度噪声生成大陆和山脊，额外物理频段覆盖 10 km、1.6 km、200 m、25 m 和 6 m，最终使用平滑界限保持高度范围。海洋行星把渲染及碰撞查询的负高度钳制到海平面。当前没有水下地形、洞穴、侵蚀或动态海浪。

## 自适应行星

每颗行星使用六个立方球面图的四叉树。观察距离和块覆盖尺度决定细分；地平线剔除、叶块预算和驻留预算限制工作。父块在可见子块准备齐全之前保留，防止生成中的洞。每帧块数和毫秒预算控制构建，CPU 同步生成一个块是最小任务单位，因此单块可能超过毫秒预算。裙边覆盖相邻 LOD 的裂缝；尚未实现完整的邻级约束及几何形变，细分弹变仍需后续优化。

连续高度采样用于网格、法线和地表高度约束。该约束不是 PhysX 全行星 MeshCollider，也不是角色重力/刚体模拟。观察者是六自由度探索相机，可降落、低空移动和起飞。

## 渲染

- URP 自定义地表 Shader 使用真实网格法线、确定性顶点生物群系颜色、太阳方向和可配置环境光。
- 恒星拥有程序化表面和温度颜色；远恒星使用三维目录点源代理，亮度经过曝光压缩和最低可见角尺寸，尚非绝对星等测光。
- 大气使用可配置 Rayleigh/Mie 密度和采样路径积分；分别合成 RGB 透射和单次入射散射，并使用相机深度终止地表路径。未实现多次散射、臭氧、云层或科学级太阳光谱。
- `Resources/UniverseSettings` 持久化 Seed、地形预算、采样数、光学系数、曝光、视场和材质。游戏内设置可调曝光、视场、星星亮度、地形预算与 Seed；其他参数通过 Inspector 调整。

## 运行与验证

`UniverseApp` 维护观察者、时钟、当前系统和参考体。星际自由飞行从观察者扇区估计空间地址，再检查相邻单元；切换恒星系保留观察者坐标。行星定位和 N 键跳转是明确的便捷传送，连续下降/上升和 WASD 飞行走同一高精度状态链。探索速度可以超过光速，当前不模拟相对论。

存档写临时文件再原子替换并保留备份，载入前验证位置、时间、姿态和生成地址。测试保护用户已有存档。

EditMode 验证数学与网格；PlayMode 验证原生对象生命周期、碰撞高度、参考体/星系切换与存档；GPU 像素验证分离天空、真空、缩放及近地深度；完整航线另外保存真实屏幕截图和帧耗时。自动断言通过仍须检查截图，本项目保留首轮视觉失败及修复证据。
