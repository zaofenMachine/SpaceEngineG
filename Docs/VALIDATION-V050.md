## 源数据、推导量与假设

| 数据类别 | 本项目含义与限制 |
| --- | --- |
| 生成参数 | 质量、半径、轨道根数、自转、外观种类及种子来自确定性合成世界，不是观测测量。模型检查不能把这些值转化为真实天体目录。 |
| 几何与运动推导 | 密度、参考半径处重力与逃逸速度依赖同一质量/半径；轨道使用直接母体质量的两体模型。卫星受热距离累加完整母体链，不能把绕行星距离错当距恒星距离。 |
| 气候模型假设 | 反照率、参考压强、干气配比/湿度、质量吸收系数、内部热及潮汐耗散参数由独立种子流和种类预设确定，尚无化学演化或行星形成模型。 |
| 温度与大气估计 | 温度为全局零维能量平衡与单层灰大气估计；密度及标高使用参考层理想气体关系。模型估计不等于实测地温、气象预报或真实垂直廓线。 |
| 未建模 / 不适用 | 使用明确文字或可空值，不用 0、NaN、无穷大冒充缺失数据。气态行星的固体地表温度/压强不适用；多周期卫星不强行显示单一太阳日。 |

`AtmosphereHeight` 仍是光学外观包络的设定高度，**不是由气压积分求得的物理大气顶**，也不应与密度标高等同。气态/冰巨行星只显示假设的 **1 bar 参考层**，没有因此新增固体地表或可降落面。黑洞“平均密度”是质量除以几何视界体积；重力和逃逸速度是该参考半径处的牛顿量，不代表可站立表面或完整广义相对论环境。

## 能量与轨道模型

当前源码使用 `S=L/(4πd²)`、`σ Teq⁴=S(1-A)/4`。固定再分配因子 4 表示全局均匀辐射的零维假设；未求解昼夜输热。内部热与适用的潮汐热以通量相加到 `σ Teff⁴`，不直接相加摄氏温度；灰层参考温度满足 `Tref⁴=Teff⁴/(1-εIR/2)`，其中 `τ=κP/g`、`εIR=1-exp(-τ)`。这些是当前模型的定义，不是完整光谱辐射传输结果。

潮汐热只在小偏心率、相对母体同步自转的卫星上使用近似，并显式列出 `k₂/Q` 假设。未适用该近似时，零附加通量不能解释成真实潮汐加热必定为零。熔岩天体的全局温度估计与局部发光熔岩温度不同，后者尚未求解。卫星食、母体反照光及热辐射亦未计入。

恒星日直接表示自转周期；一级行星的平均太阳日由自转与平均公转频率计算，顺逆行分开。同步一级行星没有有限太阳日；卫星包含绕母体及母体绕恒星的多重运动，不给出虚假的单一日长。轨道温度范围使用距恒星的保守几何界限，不是实测昼夜、季节或天气的最高最低温。两体运动仍不包含完整 N 体扰动、岁差和潮汐演化。

## 生成版本与旧版兼容

[生成版本 3 规则](../SpaceEngineG/Assets/SpaceEngine/Core/PlanetGenerationRules.cs)在原生成流程之后调整新世界的一级轨道，目标是让参考海洋世界的简化热估计与其外观有基本联系，同时保留恒星/行星半径、质量、种子与地形。布局受到恒星表面距离、Roche 距离、相邻轨道间隔及巨行星卫星空间的约束；这些是生成安全规则，不是多年 N 体稳定性证明。

无吸积黑洞宿主的恒星光度为零，不能继续靠恒星辐照维持暖海洋。新版本将相关海洋外观改为冰封储层，并对其固体天体不设置大气外观包络；内部热仍是注明假设的估计。这不代表加入了吸积盘、完整冰相图或大气逃逸模拟。不能用非零内部热温度反推液态海洋或生命条件。

生成版本 2 的恢复不运行版本 3 布局规则，保留旧轨道、种子及观察者坐标；旧版可能仍存在外观分类与简化热环境不一致，详情页显示提示而非静默篡改存档。新世界默认 `flight-v3.json`，旧版为 `flight-v2.json`；当前文件缺失时可查找旧版并按其版本恢复。存档中的世界生成版本决定所用生成器，不只取程序版本号。带精确局部坐标字段的新保存另保留 double 的往返字面值；旧存档没有该字段时仍沿用其既有数值精度。

## 官方资料与采用边界

资料与 [RESEARCH.md 的天体详情/温度模型条目](RESEARCH.md)一致，本次继续核对官方页面；没有引入其天体目录或直接复制实现。

- [SpaceEngine：Creating a planet](https://spaceengine.org/manual/making-addons/creating-a-planet)：参考质量、半径、轨道、反照率与大气参数的组织方式。本项目的参数仍为自身生成数据。
- [SpaceEngine：The Climate Model](https://spaceengine.org/articles/the-climate-model/)：参考辐照、反照率、再分配和平衡温度的关系；官方模型还包含昼夜/纬度及压力温度廓线。本轮只有注明假设的零维与单层灰模型，未复现完整系统。
- [NASA Exoplanet Archive：字段定义](https://exoplanetarchive.ipac.caltech.edu/docs/API_PS_columns.html)：用于区分质量、密度、入射通量与平衡温度的字段语义；其平衡温度不是项目可直接标作实测地温的依据。

这些资料提供语义和方法参考，不是对本项目合成世界科学精度、稳定性或宜居性的认证。
