# 开发计划与验收

目标是可实际游玩的 Unity 宇宙探索程序。以真实米制距离、确定性生成和从星际到地表的同一套空间状态为基础；不将渲染代理误称为物理天体，不将编译通过误称为图形验收通过。

## 阶段 1：坐标与生成

- 整数扇区 + 扇区内 double 米制坐标；每帧先减相机原点，再转 float。
- 恒星空间分区、Seed 恒星系、开普勒轨道、连续方向域地形函数。
- 验收：跨扇区/负坐标/极远位置的微小位移测试、Seed 重现测试、轨道周期与残差、地形连续性。

## 阶段 2：行星与渲染

- 六面 cube-sphere 四叉树，按观察距离细分，局部网格锚点，接缝裙边，生成队列与缓存预算。
- 参数化地形/海洋着色、恒星点源、星体外观、从地表到空间可用的单次大气散射。
- 验收：球面网格朝向/边界/LOD，Unity 实际渲染截图，轨道/接近/地表三个观察高度，帧耗时、网格与内存统计。

## 阶段 3：可运行探索闭环

- 自由六自由度飞行、尺度自适应速度、星系选择/导航、连续自动接近与离地、地表高度约束、时间流速。
- 打包 Windows 程序，自动路线从星际到地表；记录运行时异常、坐标、海拔、细分级别及性能。
- 验收：EditMode + PlayMode 测试，实际图形设备执行路线及截图；验证新的恒星系由 Seed 生成，避免将加载切换掩盖成连续移动。

## 后续迭代门槛

完成上述可运行闭环以后继续提升视觉与性能。后续需求包括更广的天体类型、地质细节/侵蚀、完整多次大气散射、GPU/Burst 网格生成、地形 LOD 形变、更完整的存档/星图和长时间飞行稳定性。每次迭代保留核心需求，按实际覆盖报告限制。

## 0.2：银河与天体种群

本轮优先级按依赖排列，保留 0.1 的连续降落与高精度坐标作为回归门槛。

1. 三维有限银河模型：薄盘、厚盘、旋臂、核球、棒、恒星晕；以同一密度场决定局部恒星系准入。验收 Seed 重现、分量分布、盘外空域和实际 GPU 空间顶点。
2. 七类恒星、七类行星、母星相对轨道的卫星和行星环。验收物理量范围、周期、Hill 半径、紧凑天体半径和不同地质的真实网格。气态行星必须在云层上方停住。
3. 银河人口聚合渲染、尘埃、气态云带与风暴、环影、熔岩发光。通过像素读回、不同 Seed/时间对照和实际截图检查。保留断言通过但视觉失败的首轮证据，再修复。
4. 独立 Windows 程序分别运行完整降落与银河/天体巡检，记录截图、帧时间、几何、内存、异常和退出码。新增存档使用生成版本 2，保留版本 1 原文件与程序。

本轮的“银河结构”指上述有空间厚度、有限边界和可进入邻域的合成棒旋星系；不把有限数量的聚合光核等同于逐颗实例化所有银河恒星。真实星表、星团/星云、恒星演化、双星、银河旋转势、多星系宇宙学和黑洞相对论仍属于后续系统。

## 0.3：行星材料与银河画面

根据实际画面反馈，先修正依赖网格顶点的低分辨率外观，再改善空间光学与近景轮廓。验收分为以下四步，保留生成版本 2 的地形与存档兼容。

1. GPU 生成六面高度材料图，默认每面 1024²；逐像素求海岸、地质材料、海洋反射及有界米制细节。CPU 地形仍是碰撞和网格的唯一高度来源。验收 GPU/CPU 完整 Seed 哈希、高度误差、负格点进位、面边界与网格密度不变性；另看真实轨道、低空及地面截图，不能用单独小球 fixture 替代。
2. 银河由有限三维密度场积分发光与尘埃消光，人口光核保留为小尺度点源。验收盘内/盘外/侧视、观察者移动、Seed、采样收敛、正确深度遮挡及合成方向；增加持续转动 120 帧的重算次数与帧时间，防止只测静止缓存。
3. 海洋星球增加轨道薄云，气态星球改善湍流与近景解析轮廓。验收云层 Seed/时间/光照/缩放、降落前淡出及真实云顶轮廓。仍不把云层薄片称为可进入的体积天气。
4. 全部原有测试与连续降落回归，再用相同构建 GUID 的独立 Windows 程序跑两条航线。逐张看运行截图，记录错误、帧时间、材质分辨率及内存。保存失败迭代证据；代码、测试、性能与交付说明一起提交。

本轮代码及 Editor 证据提交为 `b97dc98`，107 项 EditMode、17 项 PlayMode 与 65 项 GPU 断言通过。Windows 0.3.0 两条实际航线及追加重测均通过，26 张最终截图逐张复核；首次材料接近的帧尖峰与尚未解决的视觉边界单独登记，见 [0.3 实测记录](VALIDATION-V030.md)。

## 0.4：探索操作、中文与连续性

本轮先解决能影响正常探索的地形跳变与输入，再处理银河分辨率和信息可读性。生成版本仍为2，不以换Seed掩盖地形变化。

1. 子块从真实父三角形平滑过渡，位置、法线、颜色及高度一起变化；细分/合并加入迟滞与完整兄弟组驻留。验收端点、GPU颜色和深度、预算压力、往返阈值，再实录下降、静止、上升与原路返回。静止超过两个过渡时长后不得反复切换，径向返回误差低于1厘米。
2. 捆绑中文字体并翻译界面。增加目标选择、居中/跟踪/环绕、滚轮与键盘调速、中文搜索和物理属性筛选、详情、真实轨道、恒星系总览、精确书签与截图。选择不得暗中传送；明确区分跳转与连续飞行，输入框不得触发WASD/G。
3. 银河默认原生分辨率，分别配置外部与内部积分，为近处三维尘埃细节分配样本。对比半分辨率、关闭细节及双倍分辨率/步数参考，检查盘外/盘内/侧视与持续移动，限制孤立亮点。
4. 130 EditMode、22 PlayMode和87 GPU断言作为系统门槛；独立Windows同一构建GUID运行飞行、天体巡检、探索/实录三路线，保存退出码、截图、帧时间、静止几何状态与录像。提交源码后构建，记录源提交、字体授权和ZIP哈希。

搜索是当前和流送邻域的已解析目录，可用单元地址扩展，并非全部银河恒星的完整星表。轨道显示不是轨道编辑或N体模拟。接近时允许新几何细节逐渐显现；目标是确定、连续及稳定，而非冻结远距离低精度网格。

## 0.5：天体详情与物理一致性

2026-10-28本轮优先次序：先统一可推导的物理量，再实现中文详情页与系统关系导航，随后修复重载的一帧黑场，最后用同一Windows构建实际验收。

1. 纯函数科学数据层：质量/半径→平均密度、重力、逃逸速度；真实父体→周期、近远点、速度；完整母体链→恒星距离/辐照。区分恒星日与太阳日、平衡温度与简化地表温度、气态参考气压层与固体表面。验证地球太阳样例、卫星链、能量守恒、真空/黑洞/同步转动与非有限输入。
2. 新生成版本3按灰层模型的辐射需求放置海洋行星，不再用固定0.06AU下限强行制造冷海洋；零光度黑洞系统冻结水体并去除固体大气。保留版本2入口、原随机流和旧存档位置/地形，跨版本书签按原生成器恢复。新存档独立写flight-v3.json。
3. 详情页有概览、轨道、环境、系统与来源四个可滚动页签；数据标注生成参数、公式推导、简化假设或未建模。显示母体和卫星关系并可切换查看，不以选择暗中移动相机；F2/I与按钮均可进入，输入和鼠标滚轮隔离于飞行。
4. 渲染在LateUpdate提交，覆盖导航协程在Update之后更换世界的情况。实际冷启动颜色/深度fixture与同帧重载检查作为门槛，原生录像检查此前第60帧的初始化缺口。保留旧问题证据。
5. 完整EditMode/PlayMode回归、原87项GPU检查及新加载检查；独立程序新增详情页航线，覆盖全部天体类别、无大气、卫星、黑洞、旧版恢复和不同页签。保留截图、报告、性能、原生视频与分发哈希，再提交标签。

这里的表面温度是有假设的简化能量平衡估计，不是SpaceEngine完整气候模型；不生成未求解的生命、年龄、宜居评分或磁场强度来填充页面。
