# 视觉与界面改进（visual-pass 分支）

记录日期：2026-10-29。本轮只改画面表现和界面，不改宇宙生成、轨道、地形高度或存档格式。所有新增效果都区分了**物理模型**与**外观模型**，下文逐项注明。

## 改了什么、为什么

| 方面 | 之前的问题 | 现在的做法 |
| --- | --- | --- |
| 后处理 | 运行时相机未开后处理，恒星、高光没有任何辉光 | 相机开启 URP 后处理；`Resources/SpacePostProcess` 提供 Bloom（阈值 1，只作用于 HDR 发光体）和轻微暗角。不做全局色调映射，原有着色器的亮度标定保持不变。泛光强度可在“设置”中调。 |
| 背景星空 | 只有约 200 颗已解析恒星，高银纬方向一片漆黑 | 新增[未解析恒星层](../SpaceEngineG/Assets/SpaceEngine/Rendering/Starfield.hlsl)：四个星等层、等角立方面哈希网格、黑体色、像素尺度 PSF。每个方向的星数随**积分银河辐射**变化（尘埃带变稀、银河带变密），整体密度随**观察者所在位置的恒星数密度**变化（银河外几乎没有）。星点方向按 3000 光年区域播种，跨区边界时交叉淡化。这是外观模型：没有逐颗恒星的三维位置。 |
| 已解析恒星 | 亮度按距离粗略钳制 | 亮度来自视通量 `L/d²`（以 5 光年处的类太阳恒星为 1），对数压缩显示；像素尺度核心+光晕，亮星触发泛光。颜色改为黑体色近似（Planck 轨迹拟合）。 |
| 恒星光球 | 平涂肉色圆盘 | Worley 米粒组织 + 超米粒 + 低温星黑子与光斑；二次临边昏暗与临边泛红；柔和高光压缩，使盘面保留颜色/临边层次，中心仍超过显示白点并泛光。 |
| 日冕/眩光 | 无 | [StarGlow](../SpaceEngineG/Assets/SpaceEngine/Rendering/StarGlow.shader)：远平面绘制，被行星等不透明体遮挡；可分辨时按角半径缩放的内日冕+冕流+外晕，不可分辨时保留像素级亮核（按角面积感知压缩），远处的恒星仍可见。外观模型。 |
| 黑洞 | 黑色球面 | [史瓦西引力透镜](../SpaceEngineG/Assets/SpaceEngine/Rendering/BlackHoleLens.cs)：启动时对 `u''+u = 3/2·Rs·u²` 数值积分（RK4）得到冲击参数→偏折角查找表；冲击参数小于 `3√3/2·Rs` 的光线被俘获形成阴影，其余视线朝黑洞偏折后重新求值星空与银河辐射。屏幕外方向查银河体积新增的全天等距柱状辐射图（只随位置重算，转动视角不重算）。近似：观察者视为远离黑洞；已解析星表点和不透明天体不参与透镜；无吸积盘。恒星级黑洞和银心黑洞都会显示。 |
| 银心吸积盘 | 无 | 银心黑洞有一个光线追迹的薄吸积盘：靠近盘的视线在轨道平面内按 `u''+u = 3/2·u²` 逐步积分（RK4，步长限制每步 u 变化不超过 25%），检测穿越盘面的位置并由前到后合成，所以盘的背面会被透镜弯到阴影上下方。离开 60 Rs 后剩余偏折用弱场解析式 `(1/b)(1−√(1−b²u²))` 补齐，消除逃逸方向的量化环纹。盘：内缘在 ISCO（3 Rs），零力矩薄盘通量 `F ∝ r⁻³(1−√(r_in/r))`，开普勒速度 `√(M/(r−2M))` 的多普勒因子与引力红移，比强度按 g³ 缩放，颜色随移位后的温度变化（显示温标为可读性做了压缩），湍流条纹随较差自转剪切。外观模型，非磁流体模拟；恒星级黑洞仍按物理模型保持无吸积。核球内的曝光按局部恒星数密度做“眼睛适应”（÷ 密度比^0.6），银心不再是一片均匀的米色亮雾。 |
| 盘内银河 | 竖直的“书法笔画”状尘埃 | 原因是 360 光年尺度的各向同性三维噪声在近处被投影成竖条。尘埃细节与团块噪声改为盘面方向延展（垂直压缩 2.2–2.8 倍），细丝对比略降。现在是扁平、水平延展的暗带。 |
| 星际介质 | 尘埃带是平滑的整条暗带，没有分子云的斑驳感 | 一张 64³ 双通道可平铺 Perlin 体纹理（启动时生成）做 9 个倍频程、域扭曲的湍流，频率按射线步长做足迹滤波（远处取均值，不闪烁）。一个通道控制分子云团块（尘埃密度幂次放大），另一个控制恒星云；近处 4.5 倍几何增长步长，避免观察者附近欠采样。离观察者 350–3000 光年内的发射淡出，近处只剩尘埃剪影。消光按波长 `(0.7, 0.93, 1.3)`，云边泛红。外观模型。 |
| 盘内细丝 | 细分子云细丝取单一倍频噪声的等值线，在近处画出闭合的“烟圈”；垂直压缩 2.8 倍，远看像拉丝 | 改为两倍频脊线噪声（分叉、渐隐），垂直压缩 1.7 倍；分子云团块对比 3.1→3.6。试过把积分足迹从 0.65 步长降到 0.4，会在银带里出现沿视线的发丝状混叠，未采用。 |
| 盘内银河的直线接缝 | 银带两侧有与银道平行的笔直亮度台阶 | 两处采样分配随视线仰角离散切换：盘外段从“离开尘埃层处”开始，其起点越过近场距离时 `MarchRange` 改变近/远分段；晕的 16 个固定采样点逐个“出盒”时整点跳入。现在嵌入观察者使用与方向无关的固定预算、尘埃层之后均匀步进，晕只对盒外区间做连续积分。 |
| 银河渲染开销 | 盘内转动视角时每帧全分辨率重算体积，均值约 13 ms | 视角连续变化时（Play 模式）以半分辨率积分，停下后下一帧以全分辨率重算一次替换。同一视角下：转动时均值 13.35→5.45 ms、p95 18.4→10.4 ms（编辑器 1182×665，RTX 4070）。编辑模式与截图始终全分辨率。 |
| 行星夜面 | 环境光 0.035（线性），白云/雪在 sRGB 下约 0.2 灰，夜面像阴天 | 地表 0.006、云 0.004、气态巨行星/光环 0.005。明暗交界清晰，新月相可读。 |
| 云层 | 低频锋面 + 大尺度扭曲，像涂抹 | 纬度气候分带（赤道辐合带、副热带少云、高纬风暴带）、四个按种子分布的中纬度气旋（南北半球反向旋转）、圆润的对流云顶、更锐利的云边。覆盖率均值与原来一致，零覆盖仍完全无云。外观模型，非流体模拟。 |
| 气态巨行星 | 各向同性斑点噪声；后来是少数几条粗而均匀的“卡通”色带 | 纬向拉伸的湍流（经向长、纬向细）、边缘更锐利的带/区、每条带的种子色调、锈色色素集中在暗带、极区灰蓝雾。带数 ×1.4、射流更直；涡旋与花彩集中在带/区交界（相位扰动按 \|cos\| 加权）；增加轨道距离可分辨的中尺度纬向条纹和带内细分子带。光环按半径和光学深度变化色调，内侧更暗、外侧更亮。 |
| 轨道尺度地质 | 岩石/冰/沙漠行星从轨道看是平滑的噪声色块 | 着色器内的地质层（不改高度数据）：五个尺度的三维 Worley 撞击坑（坑底、坑缘、溅射亮纹，按足迹淡出），岩石行星的低洼“月海”，沙漠行星的干涸盆地，冰卫星沿大圆的线状裂纹（类木卫二）；坡度光照的地势放大 2.5 倍以便轨道上可读。近地时（几何细节接管）地质层淡出。材质属性默认关，验证不受影响。低平原（月海、沙海）的阈值改用粗级高度的三次 B 样条重建（双线性的等值线会在每个纹素边折角），轮廓噪声只到半径的 1/60 且在接近像素前淡出，边缘是圆润的熔岩流前缘而不是像素级碎边；月海内部按“熔岩单元”在偏蓝与偏褐之间变化并向中心变暗。沙漠：沙海边缘被沿纬圈拉伸的风纹梳开，陨石坑下风向拖出暗色风尾（类火星），坡面露出较暗的岩石。 |
| 低轨/接近视角 | 高度图纹素（地球大小约 10 km）以下没有任何起伏，直到近地网格接管前，陨石坑之间是平滑的“橡皮泥” | 着色层的亚纹素起伏：从约两个纹素到像素足迹的山脊型 fBm 坡度（宽的两个倍频程取脊线，细的平滑），按大尺度“粗糙省/平原”分区，并按地形类型加权（高地强、月海与沙海弱、海洋世界只在陆地）；沙漠上灰尘从脊顶流向洼地。陨石坑再加两个更细的种群（半径的约 1/1000、1/2900），仅在可分辨时执行。截图航线新增 36/37 号接近镜头。地质层整体约 0.5 ms。 |
| 轨道地形法线 | 夸大后的地图法线来自屏幕导数：2×2 像素块内为常数、且对近奈奎斯特的高度图求差，在明暗交界与临边处呈椒盐噪点 | 沿行星切向对滤波后的高度图做一纹素间距的中心差分，逐像素平滑、与视角无关。 |
| 明暗交界 | 撞击坑法线扰动让坑壁在夜面深处仍被照亮 | 地形光照乘以行星本体遮挡项（几何法线与太阳方向，允许约 2° 的高地余晖）。 |
| 天空光 | 地形只有一个很小的均匀环境光，日落时背光坡面一片死黑并露出三角面的折角 | 有大气的行星加天空光项：随本地太阳高度（经暮光淡出）和坡面朝向天穹的程度变化的蓝色环境光（`UniverseSettings.SkyAmbient`，正午约为直射光的 1/10）。背光雪坡在黄昏呈暗蓝色。 |
| 轨道上的大气 | 为地面天空调高的散射曝光（3）在轨道上把地表洗成灰紫 | 观察者离开大气后散射曝光平滑降到 `AtmosphereOrbitalFactor`（0.4）倍；地面天空不变。 |
| 载入时的网格 | 进入恒星系后约半秒内，轨道上能看到区块网格和一层白雾 | 刚生成的粗区块是平面弦片，片中心可低于真实球面约 0.2% 半径；大气按深度一直积分到片面，片中心多出散射、片边较暗。现在大气射线在“不可能有可见表面”的球面处截止（海洋世界为海平面，其余为最深地形）。截图航线新增诊断镜头 `arrival-fN`（回家后 N 帧即拍）。 |
| 光环与大气的合成 | 光环在大气消光之前绘制，挡在气态巨行星前方的环段被按身后行星的临边路径染成橙色 | 光环队列移到大气两遍之后（光环远在大气之外）。 |
| 光环 | 等间距的正弦条纹 | 类土星结构：C 环暗淡、B 环致密、卡西尼缝、A 环与恩克缝、窄 F 环，叠加按种子的细密小环；颜色按光学深度。外观模型。 |
| 河外星系 | 银河外的天空完全空白 | [Starfield.hlsl](../SpaceEngineG/Assets/SpaceEngine/Rendering/Starfield.hlsl) 的 `DistantGalaxies`：每个立方面 9×9 格稀疏分布的椭圆/旋涡星系贴片（至少约 2 像素宽并守恒通量），外加一个类仙女座的大倾斜旋涡；被本银河亮带按亮度遮挡，透镜路径同样绘制。只有方向与形状，没有位置、星表条目或物理，不能被搜索或选中。 |
| 熔岩天体 | 均匀细线网 | 区域活动度：活跃省份有宽阔熔岩流，其余为发丝裂缝；裂缝中心橙黄、边缘深红，周围地壳有热辉光。 |
| 近地地形 | 远处粗块的地图法线对 float 单位方向求屏幕导数，在地面附近量化成噪点 | 地图法线切线改用相机相对的米制梯度；像素足迹远小于高度图纹素（约 11 km）时淡出地图法线，交给网格法线。另外：陡坡露出岩石、沙滩带收窄、近地森林/草地斑块（轨道距离被足迹滤波为均值，不改变轨道外观）。 |
| 近地材质 | 着陆后是一片纯色的平滑丘陵 | 六层地面细节贴图数组（草地、干土、岩石、沙、雪、风化层），原图由图像生成得到，再经 [build_ground_textures.py](../Scripts/build_ground_textures.py) 做无缝交叉淡化、去低频漂移、存为“相对图层均值的比值”并由亮度高通生成法线。着色器按各类行星已有的生物群系计算图层权重，每像素取最强两层，以星球固定的米制坐标做三平面投影（贴图周期整除 16384 m 图表周期，跨区块无缝），2 m 与 16 m 两个尺度相乘以打破重复，并用 whiteout 混合法线。细节随像素足迹在约 0.5 m/3 m 处淡出：轨道外观、生物群系颜色和全部 GPU 验证（材质默认强度为 0）都不变。 |
| 白天天空 | 星点在蓝天中可见；地面天空只有沙地亮度约 1/7 | 根据观察者在大气中的深度与太阳高度计算 `Daylight`，淡化星空、星表、银河粒子与体积（`Daylight` 达到约 0.9 时完全淡出，此前白天仍残留 3% 的银河，在亮天中呈两道竖光）；恒星日冕在白天同样淡出；大气曝光 1.6→3。 |
| HUD | 五六块不透明面板占约一半画面，并常驻显示三角形数、扇区、64 位精度等开发遥测 | 半透明圆角面板（运行时生成 9 宫格纹理，不依赖可能未打包的 IMGUI 内部着色器）；取消全宽顶栏/底栏；工具栏、目标条、遥测都收紧；恒星系列表可折叠，银河总览时自动折叠；开发遥测改为 **F10** 开关；状态文字带阴影直接叠在画面上。详情、搜索、书签、标签同一套样式。 |

## 新增设置

`UniverseSettings` 新字段（资产中未写入时使用默认值）：`StarfieldBrightness`（1）、`StarSurfaceRadiance`（2.8）、`PostProcessing`（开）、`BloomIntensity`（0.6）、`CentralAccretionDisk`（开）、`AccretionDiskRadiance`（2.5）、`AccretionDiskOuterRadius`（14 Rs）。地面细节强度在 `Resources/Terrain.mat` 的 `_GroundDetailStrength`（1）。调整过的默认值：`AmbientLight` 0.006、`AtmosphereExposure` 3（地面）、`AtmosphereOrbitalFactor` 0.4（轨道上相对地面的倍数）、`SkyAmbient`（0.07, 0.11, 0.19）。游戏内“设置”新增“背景星空亮度”“泛光强度”和“开发信息 F10”。

## 已知局限与下一步

- 没有全局色调映射和自动曝光；HDR 只用于发光体。全局 ACES/Neutral 需要整体重标定各着色器的曝光。
- 透镜不重新追踪已解析星表点、行星和光环；查表路径把观察者视为远离黑洞（靠近吸积盘的光线是逐步积分的）。吸积盘是几何薄、光学厚度按噪声变化的外观模型，没有喷流、厚盘或盘的自遮挡阴影。
- 背景星空是统计外观层，不能被搜索或选中。
- 地面细节是贴图层，没有植被、石块等几何体；熔岩天体的发光裂缝会覆盖地壳细节；六张源图由生成得到，同一图层在大片平地上仍可能看出 16 m 级的重复。
- 白天天空亮度按经验调整，未与地表辐照做严格的光度标定。

编辑器内迭代：Play 模式下通过 Unity MCP 调用 `ShowcaseCapture.Shoot(folder, "镜头名,...")`，相机直接渲染到 1600×900 目标（不含 HUD）；只改着色器时无需退出 Play 模式。帧时间：在 `UniverseApp` 上挂 [FrameProbe](../SpaceEngineG/Assets/SpaceEngine/Runtime/FrameProbe.cs)，`Measure(标签, 帧数, 每帧转角)` 后读 `FrameProbe.LastReport`（转角非零时相机来回转动，强制天空缓存逐帧重算）；测量前把 `Application.targetFrameRate` 设为 -1 解除 120 帧上限。
