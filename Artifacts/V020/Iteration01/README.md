# First rendered review, not visual acceptance

The runtime assertions passed, but direct inspection of the actual Editor PNGs found oversized aggregate bokeh, dust quadrature missing the thin disk, ring moire, vertex-interpolated lava triangles and a flat cloud-top approach. These images preserve the failures. Later per-pixel filtering, clipped dust integration, bounded kernels, fragment lava and cloud detail fixed them; see the final V020 evidence and validation record.
